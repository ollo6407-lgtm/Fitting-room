Gemini API Key 10초 발급 가이드 (별도 로그인/서버 없이 바로 실행)

  1. 위의 Google AI Studio (aistudio.google.com/app/apikey) 링크로 이동해 구글 계정으로 로그인합니다.
  2. 우측 상단 [Create API key] 버튼을 클릭해 키(AIza...)를 생성 및 복사합니다.
  3. 복사한 키를 우측 입력창에 붙여넣으면 즉시 선택한 Gemini 이미지 모델에 적용됩니다.
